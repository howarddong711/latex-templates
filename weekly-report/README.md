# 研究周报模板

- `main.tex`：配色、字体、页眉页脚、标题与参考文献设置。
- `week.tex`：姓名、邮箱、汇报日期、副标题与研究方向。
- `content.tex`：正文；章节可按每周实际工作自由调整。
- `references.bib`：文献条目。
- `build.ps1`：Windows 编译入口，需 XeLaTeX、latexmk、Biber。

日期填写当天，例如 `2026.10.25`。作者与邮箱只在文首显示，页脚只显示页码。章节连续排版，避免不必要的手动分页。示例信息均为占位内容。
